## What this tab is for
The Playground lets you test any configured model, through the gateway, without leaving the console — useful to validate a route, compare answers or check real latency.

## How to use it
Pick the model and the feature (cost dimension), adjust creativity and length, then send the prompt. The call goes out with your API key and produces attributed cost, exactly like a production request.

## Common questions
- **Why "No model configured"?** Connect a provider in Models & Routing first.
- **Do I need an API key?** Yes — save a gateway key under Settings so the Playground can make the call.
- **Auto-cheapest swapped my model.** Turn auto-cheapest off to force the model you picked for the test.
