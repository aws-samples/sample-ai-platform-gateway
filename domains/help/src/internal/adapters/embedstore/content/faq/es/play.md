## Para qué sirve esta pestaña
El Playground te deja probar cualquier modelo configurado, por el gateway, sin salir de la consola — útil para validar una ruta, comparar respuestas o verificar la latencia real.

## Cómo usarla
Elige el modelo y la función (dimensión de costo), ajusta creatividad y tamaño, y envía el prompt. La llamada sale con tu API key y genera costo atribuido, igual que una solicitud de producción.

## Preguntas frecuentes
- **¿Por qué dice "Ningún modelo configurado"?** Conecta un proveedor en Modelos y enrutamiento primero.
- **¿Necesito API key?** Sí — guarda una clave del gateway en Configuración para que el Playground pueda llamar.
- **El auto-cheapest cambió mi modelo.** Apaga el auto-cheapest para forzar el modelo que elegiste en la prueba.
