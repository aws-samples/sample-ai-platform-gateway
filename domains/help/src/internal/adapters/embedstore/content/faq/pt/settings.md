## O que a aba resolve
Configurações reúne os dados da sua organização, a API key do gateway usada pelo console (Playground), os membros da org e a segurança da conta.

## Como usar
Salve aqui a API key do gateway para habilitar o Playground. Em Membros, convide pessoas e defina o papel (owner/admin/billing/dev); no Business, o acesso é organizado por time. A org vem do seu login e é somente leitura.

## Perguntas comuns
- **Não consigo trocar minha org.** A org vem do token — é a sua conta. Só um operador da plataforma cruza orgs.
- **Qual a diferença entre papel e time?** Papel é o que a pessoa faz (owner/admin/…); time é o escopo de recurso que ela alcança (no Business).
