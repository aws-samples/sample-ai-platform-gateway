## O que a aba resolve
O Playground deixa você testar qualquer modelo configurado, pelo gateway, sem sair do console — útil para validar uma rota, comparar respostas ou checar latência real.

## Como usar
Escolha o modelo e a feature (dimensão de custo), ajuste criatividade e tamanho, e envie o prompt. A chamada sai pela sua API key e gera custo atribuído, como uma requisição de produção.

## Perguntas comuns
- **Por que "Nenhum modelo configurado"?** Conecte um provedor em Modelos & Roteamento primeiro.
- **Preciso de API key?** Sim — salve uma chave do gateway em Configurações para o Playground poder chamar.
- **O auto-cheapest trocou meu modelo.** Desligue o auto-cheapest para forçar o modelo escolhido no teste.
